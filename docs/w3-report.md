## 2. 招募概率假设检验（SQL Q4 + 逐 seed 明细）

```
Q4 保底开关对整体 6★ 率的影响（招募）
pity_enabled  runs  pulls      n6      rate6_pct
0             4     1000000    19941   1.9941     ← 关闭保底 ≈ 声明 2%
1             4     1000000    28861   2.8861     ← 开启保底抬升 +0.89pct

逐 seed（每段 25 万抽）：pity=off max_gap 最高 510（纯随机间隔无上界）；
                        pity=on  max_gap ≤ 79 ≤ 100（REQ-PRB-003 有界）
```

**结论**：关闭保底时 100 万抽 6★ 率 1.9941%（95% 二项置信区间含声明值 2%，χ² 检验通过）；
开启保底后 2.886% > 基础概率 2%（REQ-PRB-007 成立），且最长连不出 ≤ 79 抽 < 100 保底线。

## 5. 面试口径

- "区间哪来的？" → REQ-BAL 设计目标 + 2000 局蒙特卡洛基线校准，见 tests/test_balance.py；
- "为什么用 χ²？" → 三档稀有度拟合优度，df=2、期望频数 ≫5 满足适用条件（无 scipy 的临界值法，
  引入 scipy 后可得精确 p 值，结论一致）；
- "SQL 有什么意义？" → 平衡回归产物可落库、可回放、可自动化比对（W5 CI 每日回归的基础），
  数据反哺调优建议（Q2 即"该上真伤干员"的证据）。
